Kaipoke (カイポケ)

Vendor: SMS (エス・エム・エス)

Type: All-in-one cloud billing suite, from planning through claims.

Segments: Home care, facility, day/rehab — the widest service coverage of any single brand.

Scale: 62,300 offices including Kabenashi Cloud (end of June 2026).

Pricing: ¥1,000/month in the first year; ¥25,000/month from year 2 on (home visit). Free trial.

Source: Kaipoke Profile

Honobono NEXT (ほのぼのNEXT)

Vendor: SOMPO (NDSoftware subsidiary)

Type: On-prem or hosted; billing and records.

Segments: Home care, facility, day/rehab.

Scale: 64,800 offices. The largest by claimed install base.

Note: SOMPO's care-insurance subsidiary uses Honobono internally.

Source: Honobono NEXT Profile

Kanamic (カナミック)

Vendor: Kanamic Network (カナミックネットワーク)

Type: Cloud billing; records; medical-care coordination (MCS linkage).

Segments: Home care, facility, day/rehab.

Scale: 52,500 offices (November 2024).

Note: Kanamic also has home-care data-exchange integration and medical-care chat features.

Source: Kanamic Profile

Wiseman (ワイズマン)

Vendor: M3 (consolidated from July 2026)

Type: Full billing package — initial fee plus five-year usage-right pack; includes claims.

Segments: Home care, facility (strong tokuyō presence).

Scale: 50,000+ facilities.

Note: Perpetual-license model; five-year usage-right renewals.

Source: Wiseman Profile

Care-wing (ケアウイング)

Vendor: M3 (formerly Logic, acquired April 2022)

Type: Records front-end: IC-card sign-in for home-visit workers. Does not make insurance claims itself; pairs with billing software.

Segments: Home care.

Note: Popular as an attendance-tracking layer. Simple pricing.

Source: Care-wing Profile

CAREKARTE (ケアカルテ)

Vendor: Care Connect Japan (CCJ)

Type: All-in-one billing suite for facilities; claim data is created automatically from the records.

Segments: Facility, day/rehab (tokuyō, group homes, day care).

Note: Records-first design: write the care record and get the claim for free.

Source: CAREKARTE Profile

Rehab Cloud (リハブクラウド)

Vendor: Rehab (リハブ)

Type: Specialist cloud for day-care and rehab centres; built around add-ons and LIFE data.

Segments: Day care, day rehab.

Features: Individual functional training (個別機能訓練), scientific-care add-on, nutrition management, plus integrated billing. Completed V4 vendor-test patterns D1–D7.

Source: Rehab Cloud Profile

ZEST (ゼスト)

Vendor: ZEST

Type: Specialist: scheduling and dispatch for day-care pick-up vehicles.

Segments: Day care.

Note: Not a billing system; integrates with billing suites via CSV/API.

Source: ZEST Profile

SmaCare (スマケア)

Vendor: Homenet

Type: Records front-end: mobile entry for home-visit workers; GPS, speech-to-text.

Segments: Home care (home-visit).

Note: Pairs with billing software (Kaipoke, Honobono, etc.).

Source: SmaCare Profile

Tako-San's View

Opinion:

M3's strategy is to own both ends: Wiseman for facility billing and Care-wing for home-visit records. They're betting most providers need one or the other; few need both in one product. This "records front-end + billing back-end" split is the most common architecture I've seen in the market.
