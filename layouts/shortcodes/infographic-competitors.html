Kaipoke (カイポケ)

Vendor: SMS (エス・エム・エス)

Type: All-in-one cloud billing suite, from planning through claims.

Segments: Home-based services; SMS says it does not cover facility-type services such as group homes.

Scale: 62,300 offices including Kabenashi Cloud (end of June 2026).

Pricing: ¥1,000–¥25,000 a month per service type, excl. tax (e.g. ¥25,000 home-visit care, ¥5,000 care management); 2-month free trial.

Source: Kaipoke Profile

Honobono NEXT (ほのぼのNEXT)

Vendor: ND Software Co., Ltd. (wholly owned by SOMPO Holdings since 28 Feb 2023)

Type: Five-year software licence; records linked to care-insurance claims; cloud version available.

Segments: Home care, facility, day/rehab.

Scale: More than 72,300 offices (Apr 2026, ND Software's own count).

Source: Honobono NEXT Profile

Kanamic (カナミック)

Vendor: Kanamic Network (カナミックネットワーク)

Type: Cloud billing; records.

Segments: Home care, facility, day/rehab.

Scale: 57,763 offices (Mar 2026, company figures).

Note: Approved by an MHLW panel as equivalent to the Care Plan Data Exchange (care-management fee type II); team features include care chat.

Source: Kanamic Profile

Wiseman (ワイズマン)

Vendor: M3 (consolidated from July 2026)

Type: Full billing package — initial fee plus five-year usage-right pack; includes claims.

Segments: Home care, facility. M3 claims ~40% of geriatric health facilities, ~25% of special nursing homes.

Scale: More than 61,200 care offices, excl. disability (Wiseman's own count).

Source: Wiseman Profile

Care-wing (ケアウイング)

Vendor: M3 (formerly Logic, acquired April 2022)

Type: Records front-end: smartphone + IC-tag records for home-visit workers. Does not make insurance claims itself; pairs with billing software.

Segments: Home care, home-visit nursing.

Source: Care-wing Profile

CAREKARTE (ケアカルテ)

Vendor: Care Connect Japan (CCJ)

Type: Records-to-claims system with a strong facility base. Claim data is created automatically from service records.

Segments: Home care, facility, day/rehab.

Source: CAREKARTE Profile

Rehab Cloud (リハブクラウド)

Vendor: Rehab for JAPAN Co., Ltd.

Type: Specialist cloud for day-care and rehab centres; built around add-ons and LIFE data.

Segments: Day care, day rehab.

Features: Individual functional training (個別機能訓練, kobetsu kinō kunren), scientific-care add-on, nutrition management, plus integrated billing. Completed V4 vendor-test patterns D1–D7.

Source: Rehab Cloud Profile

ZEST (ゼスト)

Vendor: ZEST Inc.

Type: Specialist: visit scheduling and route optimisation for home-visit nursing and care.

Segments: Home-visit nursing and care.

Note: Not a billing system; links with Kaipoke, CAREKARTE and others (link method not stated in sources).

Source: ZEST Profile

SmaCare (スマケア)

Vendor: Homenet

Type: Records and schedules for 24-hour regular-visit and on-call home care and nursing (定期巡回・随時対応型訪問介護看護, teiki junkai zuiji taiō-gata hōmon kaigo kango).

Segments: Home care (regular-visit).

Note: Pairs with billing software (e.g. TriCare-Tops).

Source: SmaCare Profile

Tako-San's View

Opinion:

M3's strategy is to own both ends: Wiseman for facility billing and Care-wing for home-visit records. They're betting most providers need one or the other; few need both in one product. This "records front-end + billing back-end" split appears to be a common architecture among these competitors.
